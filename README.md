# Wellness Lab — website

Στατικό site (HTML/CSS/JS, χωρίς build) για το **wellness.lab.gr** — διατροφή | υγεία | ευεξία.

## Τι πρέπει να συμπληρωθεί
Ψάξε για `ΑΛΛΑΞΕ` στα αρχεία:
- `index.html` — όνομα διατροφολόγου, τηλέφωνο, email, διεύθυνση γραφείου, σπουδές.
- `index.html` — φωτογραφία της (βάλε `assets/photo.jpg` στη θέση του placeholder).
- `script.js` — `CONTACT_EMAIL`, το email όπου πηγαίνουν τα μηνύματα της φόρμας.
- Προαιρετικά: αντικατάστησε το `assets/logo.svg` με το πραγματικό λογότυπο.

## Δωρεάν φιλοξενία
Ενεργοποίησε το **GitHub Pages** (Settings → Pages → Deploy from branch) ή ανέβασε τον φάκελο στο Netlify / Cloudflare Pages.
