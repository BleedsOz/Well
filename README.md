# Wellness Lab — website & εφαρμογή διατροφής

- **`/`** — η δημόσια σελίδα (διατροφή | υγεία | ευεξία).
- **`/app/`** — η εφαρμογή με σύνδεση:
  - **Διατροφολόγος (admin):** πελάτες, στόχοι ανά πελάτη (θερμίδες, πρωτεΐνη, υδατάνθρακες, λιπαρά), πρόγραμμα διατροφής ανά ημέρα και γεύμα, βιβλιοθήκη τροφίμων, ημερολόγιο του τι έφαγε ο πελάτης.
  - **Πελάτης:** βλέπει το πρόγραμμα της ημέρας, αλλάζει ένα γεύμα με γεύμα άλλης ημέρας, προσαρμόζει ποσότητες και βλέπει live πόσο απέχει από τους στόχους του. Το κουμπί «Προσάρμοσε ποσότητες στον στόχο» κλιμακώνει αυτόματα τα γεύματα που δεν έχει φάει ακόμα.

Όλο το site είναι στατικό (HTML/CSS/JS, χωρίς build). Για λογαριασμούς και βάση δεδομένων χρησιμοποιεί το **Supabase** (δωρεάν πακέτο).

## Δοκιμή χωρίς ρύθμιση (demo)
Όσο το `app/config.js` είναι κενό, η εφαρμογή τρέχει σε **λειτουργία demo**: έχει έτοιμους λογαριασμούς («Ως διατροφολόγος» / «Ως πελάτης») και κρατά τα δεδομένα μόνο στον browser.

Τοπικά: `python3 -m http.server` στον φάκελο και άνοιξε http://localhost:8000/app/

## Ρύθμιση για πραγματική χρήση (~10 λεπτά)
1. Φτιάξε δωρεάν λογαριασμό στο https://supabase.com και ένα νέο project (region: Frankfurt / EU).
2. **SQL Editor → New query**: επικόλλησε όλο το `supabase/schema.sql` και πάτα **Run**.
3. **Project Settings → API**: αντέγραψε το *Project URL* και το *anon public key* στο `app/config.js`.
4. **Authentication → URL Configuration**: βάλε στο *Site URL* τη διεύθυνση του site (π.χ. `https://wellnesslab.gr/app/`).
5. Η διατροφολόγος κάνει εγγραφή από το `/app/#register`. Μετά, στο SQL Editor:
   ```sql
   update public.profiles set role = 'admin' where email = 'to-email-tis@example.com';
   ```
6. Οι πελάτες κάνουν εγγραφή από τον σύνδεσμο που βρίσκει η διατροφολόγος στο admin panel.

Το anon key επιτρέπεται να είναι δημόσιο: την πρόσβαση την ελέγχουν οι κανόνες Row Level Security του `schema.sql` (ο κάθε πελάτης βλέπει μόνο τα δικά του, μόνο η admin αλλάζει προγράμματα και στόχους).

## Τι πρέπει να συμπληρωθεί στη δημόσια σελίδα
Ψάξε για `ΑΛΛΑΞΕ`: όνομα, τηλέφωνο, email, διεύθυνση, φωτογραφία (`assets/photo.jpg`), email φόρμας στο `script.js`.

## Δημοσίευση
GitHub Pages (Settings → Pages → Deploy from branch), Netlify ή Cloudflare Pages — δωρεάν.

## Σημείωση για προσωπικά δεδομένα
Τα δεδομένα διατροφής/υγείας είναι ευαίσθητα (GDPR). Καλό είναι να προστεθεί σελίδα «Πολιτική απορρήτου» και οι πελάτες να ενημερώνονται/συναινούν κατά την εγγραφή.
